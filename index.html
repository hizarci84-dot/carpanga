Öğretmen Paneli & Firebase Veritabanı Ayarları

Yerel Mod

Okuldaki tüm Pardus akıllı tahtaların aynı veritabanına kayıt yapması için Firebase projenizin Web yapılandırma (firebaseConfig) bilgisini aşağıya yapıştırın.

📘 2 Dakikada Ücretsiz Firebase Kurulum Adımları (Tüm Tahtalar İçin Ortak Veritabanı)
  1. console.firebase.google.com adresine Google hesabınızla girip Add project ile bir proje oluşturun (ör. carpanga-okul).
  2. Sol menüden Build → Firestore Database → Create database seçin, test/üretim modunda açın ve Rules sekmesinden carpanga_matches koleksiyonu için okuma/yazmaya izin verin (ayrıntılı kural kodu README.md içindedir).
  3. Sol üst çark ikonundan Project settings → Your apps → Web (</>) ekleyin ve çıkan firebaseConfig nesnesini kopyalayıp aşağıya yapıştırın.
  4. Kalıcı olması için aynı config'i GitHub reponuzdaki js/firebase-config.js dosyasına da kaydedebilirsiniz veya aşağıdaki Kurulum Linki Kopyala butonuyla tüm tahtalara tek linkten aktarabilirsiniz.
